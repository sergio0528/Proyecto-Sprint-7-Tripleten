# Proyecto-Sprint-7-Tripleten
Repositorio para el proyecto del Sprint 7 de Tripleten
Se configura una aplicación para examinar las caracteristicas de los vehiculos de la base de datos entregada.

La aplicación cuanta con funcionalidades como histograma y grafico de dispersión de los datos.

Cabe aclarar que los requerimientos del proyecto son Python, pandas, plotly y Streamlit.
